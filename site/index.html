The first job is to understand what you’re making. Then give it a point of view, explore ways to express it, and check the work where it will actually live.

Find the truth.

Who is this for? What changes for them? Start with the product, the audience and the things you can prove.

Take a position.

Choose what the brand stands for, how it should feel, and what makes it worth someone’s attention.

Choose your agent, copy the command, and run it in your terminal. branded is ready across your projects.

INSTALL ONCE. USE IN EVERY PROJECT.

Bring your agent.

npx -y github:Atmech/tech-branding-logo-repo#6359f0a --agent codex --global

No manual cloning. No folder copying. Requires Node.js 18+ and Git.

Installs for all projects. Mention $branded in your next chat.

Current branded preview · pinned source version 6359f0a

THEN ASK YOUR AGENT

“Use branded to help me build a brand for…”

Bring the product, the audience, and anything you already know. We’ll start there.
Prefer native Codex or Claude plugins?

Add our repository marketplace and install branded with your host’s own plugin manager. These are repository integrations, with no account connection required.

Codex plugin

codex plugin marketplace add Atmech/tech-branding-logo-repo --ref codex/easy-install && codex plugin add branded@branded

Then start a new chat and use the branded skill.

Claude Code plugin

claude plugin marketplace add Atmech/tech-branding-logo-repo#codex/easy-install && claude plugin install branded@branded

Then start a new session and run /branded:branded.

Uses our preview branch. Availability depends on your host version and workspace policy.
