The product experience

Onboarding is installation. Branding starts when you ask for it.

The portable skill carries the workflow. The optional CLI manages installation and project files. Your agent can start a brief directly, without a setup questionnaire.

Install

Use a portable folder or native plugin. With the optional CLI, choose your agent and install for this project or all local projects.

Brief

Tell your agent what you are making. It reads existing context and asks only consequential questions. The optional brief command also creates project memory.

Brand

Your agent uses SKILL.md and the reference system to do the actual positioning, naming, logo exploration, refinement, and QC.

Resume

The project state lives in .branding/, so another supported agent can pick up the same work without restarting discovery.

What you can make

A new identity. A campaign. The next thing your brand needs.

Start where you are. branded reads the existing project, works out what the brief needs, and brings in the relevant industry guidance.

01 / IDENTITY

Build a lasting brand.

Start from zero, build around an existing name, or evolve a familiar identity. Connect positioning, naming and a usable visual system.

02 / CAMPAIGN

Give the moment a direction.

Develop a launch, promotion or collection with a concept, key visual and channel assets. Keep temporary choices separate from the master brand.

03 / APPLICATION

Put your brand to work.

Create posts, packaging, presentations and other assets within the identity you already have, with checks for the intended surface.

04 / CONTEXT

Bring the right expertise.

Technology, food and hospitality, real estate, fashion and apparel. Add B2B buying context or packaging guidance when the brief calls for it.

Portable project memory

Your branding work should not disappear when the chat ends.

The CLI creates a lightweight project state that agents can read and continue. Discovery stays separate from branding conclusions, so the skill can challenge assumptions instead of blindly repeating them.

Continue, don’t restart.

Use resume to inspect what is already known and where the brand workflow stopped. Use doctor to verify the installation. Use export to collect the finished work into a shareable brand kit.

The expertise layer

A considered method, from the first question to the final file.

A focused brief shapes the work. The skill connects strategy, creative exploration, editable assets and quality checks, using the tools available in your agent.

Product truth

Audience, job, alternatives, promise, proof, constraints, ambition, and the future the brand must support.

Brand foundation

Transformation, role, positioning, personality tensions, anti-positioning, verbal tone, and visual territories.

Logo system

For identity work: concrete brand nouns, broad exploration, distinct routes, and black-and-white refinement.

Product proof

Check the intended use: identity lockups, campaign channels, packaging or other brand assets. Record limitations and final QC.
