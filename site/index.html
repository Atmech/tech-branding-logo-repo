The product experience

Onboarding is installation. Branding starts when you ask for it.

The CLI handles setup and project state. The skill remains the branding brain. That separation keeps the experience simple without watering down the methodology.

Install

Run one command. The CLI detects supported agents and installs the skill safely without overwriting unrelated files.

Brief

When you are ready to brand something, run brief. The questions adapt to the chosen entry mode and only ask what can change the direction.

Brand

Your agent uses SKILL.md and the reference system to do the actual positioning, naming, logo exploration, refinement, and QC.

Resume

The project state lives in .branding/, so another supported agent can pick up the same work without restarting discovery.

Works where you work

Three entry points

Different starting points. One coherent methodology.

The discovery questions change depending on what already exists. The branding expertise underneath does not.

01 / ZERO

Zero-to-brand

No name yet. Resolve product truth, positioning, naming, visual territories, logo, and identity system.

02 / NAME

Name-to-brand

You already have a name. Assess its fit, build meaning from the product, then create the visual system around it.

03 / EVOLVE

Brand evolution

Audit what exists, decide what to retain/evolve/retire, and design the next system with continuity in mind.

04 / SHARED

Same engine

Positioning, brand nouns, broad concept generation, black-and-white refinement, product testing, and QC.

Portable project memory

Your branding work should not disappear when the chat ends.

The CLI creates a lightweight project state that agents can read and continue. Discovery stays separate from branding conclusions, so the skill can challenge assumptions instead of blindly repeating them.

Continue, don’t restart.

Use resume to inspect what is already known and where the brand workflow stopped. Use doctor to verify the installation. Use export to collect the finished work into a shareable brand kit.

The expertise layer

The CLI understands the request. The skill knows how to brand.

Questions are for context and direction. The method for strategy, naming, visual exploration, refinement, testing, and system-building already lives in the skill and its references.

Product truth

Audience, job, alternatives, promise, proof, constraints, ambition, and the future the brand must support.

Brand foundation

Transformation, role, positioning, personality tensions, anti-positioning, verbal tone, and visual territories.

Logo system

Concrete brand nouns, 50+ low-cost directions, shortlisting, three distinct routes, and black-and-white refinement.

Product proof

App icon, favicon, UI, light/dark, monochrome, lockups, patterns, tokens, guidelines, and final QC.
