# Contributing

Contributions should improve the skill’s usefulness across agent environments without making the core workflow unnecessarily long.

Before opening a pull request:

1. Keep `SKILL.md` focused on routing and essential procedure; put detailed guidance in `references/`.
2. Preserve the three operating modes and the deliverable schemas.
3. Avoid unsupported legal, trademark, or market-success claims.
4. Validate frontmatter, metadata, links, and archive integrity.
5. Explain behavioral changes and include a representative use case.
