# Logo workflow

## Concept engine

Translate strategy into 15–25 concrete brand nouns; narrow to about 15 approved nouns. Generate at least 50 rough concepts before polishing. Combine nouns through overlap, negative space, rhythm, flow, modularity, or an unexpected but legible twist. Avoid generic category shorthand unless it is transformed into a distinctive structure.

## Refinement order

1. Black-and-white silhouette and recognition.
2. Geometry, optical balance, proportions, spacing, and line weight.
3. Wordmark and type pairing.
4. Color and contrast.
5. Lockups: symbol, wordmark, horizontal, stacked if useful, app icon, favicon, social avatar, light/dark, monochrome.
6. Visual-DNA extensions: icons, patterns, UI shapes, illustration, motion, and data graphics.

## Functional tests

Inspect at 16×16 favicon scale, app-icon scale, header scale, and large presentation scale. Test one color, black/white, light/dark backgrounds, grayscale, approximate embroidery/engraving, low-resolution reproduction, and adjacent competitor context. Check whether the identity still works without the full logo being oversized.

## Production notes

Prefer clean paths, explicit viewBox, no accidental raster dependency, sensible naming, and editable source. Include clear space, minimum size, misuse examples, and export list. Do not force a badge into a software identity; use one only when it has a real product or community role.
