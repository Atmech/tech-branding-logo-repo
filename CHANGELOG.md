## 1.0.0

Initial CLI product layer around the Tech Branding & Logo skill.

- Dependency-free Node 18+ CLI.
- Caveman-style installation onboarding with agent auto-detection.
- Safe local install manifest for update/uninstall.
- Supported targets: Codex/OpenAI, Claude Code, Cursor, Windsurf, Gemini CLI, and generic agents.
- Persistent `.branding/` project memory shared across agents.
- Mode-aware `brief` flow for zero-to-brand, name-to-brand, and brand-evolution work.
- `resume`, `doctor`, `update`, `export`, and `uninstall` commands.
- State/install schemas and installer smoke tests.
