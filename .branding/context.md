# branded — compact identity brief

Scope: lasting identity / brand evolution. Name: branded, already selected by the owner. Product: open-source agent skill for identities, campaigns and applications, with optional CLI and portable project memory.

Request: use branded on itself; develop brand psychology, a good logo and practical branding examples; update the homepage and keep installation instructions accurate. The owner explicitly loves the supplied existing design: paper, ink, lime, coral, oversized editorial serif and worktable composition. Preserve these cues.

Assumed primary audience: builders and small teams already working with agents. Desired action: understand the promise and choose a valid installation path. Desired feeling: creative confidence grounded in understanding the work.

Recommended platform: “Make it mean something.” Supporting promise: “A clear point of view. A brand you can build on.” Recommended identity: considered-cut lowercase b and outlined wordmark. These are design recommendations, not owner approvals.

Useful modules: brand strategy and identity workflow structure the work; technology module informs digital recognition, host constraints and file checks; rebrand audit preserves explicitly liked cues; logo workflow guides monochrome construction and exports. No B2B or packaging overlay needed for the skill's own identity.

Deliverables: strategy/psychology; nine type-led studies and three directions; SVG logo variants, favicon, skill icon, avatar/social exports; updated homepage and public brand playbook; tokens, guidelines, QC, final manifest. Sources under brand/identity and site/assets. Installed skill instructions are not rewritten for this design task.

Constraints: name and repository URLs remain; no invented customer proof, name clearance, universal color psychology, package publication or live deployment claims. Native and local CLI installation must match actual paths and supported scopes. Existing user project state and approvals stay intact.

Open: owner review of the proposed mark and voice, actual audience response, competitive screening and live deployment. Hypotheses are identified in the strategy.
